# FormKit

A responsive, app-like static web app for preparing images/documents for online forms.

## Included
- Photo resize/compress
- Signature resize/compress
- Thumb impression
- Handwritten declaration
- General image tools
- Image-to-PDF
- Responsive mobile-first UI
- SVG-style icons / icon treatment
- Privacy, Terms, Disclaimer, Contact pages
- SEO meta tags, robots.txt, sitemap.xml

## Run
Open `index.html` in a modern browser or deploy the folder to any static host.

## Before publishing
- Replace `example.com` in sitemap/robots/canonical URLs with your real domain.
- Replace support@example.com on `contact.html`.
- Review policy text for your actual business, analytics, ads, hosting and jurisdiction.
