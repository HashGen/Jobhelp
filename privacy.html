Privacy Policy

Simple, readable information about using FormKit.

FormKit is designed as a browser-based utility. The image-processing features in this static version are performed on your device using JavaScript.

Information we receive

We do not require an account. Files you select for image processing are not intentionally uploaded to our server by the app code in this package.

Third-party services

The app may load fonts from Google Fonts and the PDF utility library from a public CDN. Those services may receive normal browser network information when a resource is requested.

Cookies and analytics

This package does not include advertising trackers or analytics code by default. If you add analytics later, update this policy before deployment.
